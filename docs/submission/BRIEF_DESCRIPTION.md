# Dashboard brief description

Daymark is a private Gemini journal built as a same-origin React and Express application for Cloud Run. Firebase Authentication provides Google Sign-In; the server verifies each Firebase ID token and derives the user ID before any data access. Firestore stores journals, ordered messages, summaries, themes, next steps, and Context Contract memories beneath that verified user, so one user cannot query another user's records. Gemini is called only by the server through the official `@google/genai` SDK for bounded multi-turn replies and structured summaries. The Gemini authorization key is intended to be injected from a numbered Google Cloud Secret Manager revision into Cloud Run, never shipped to the browser or committed to source. The original enhancement is consentful memory: Gemini may propose facts, commitments, preferences, or questions, but only the user can approve, edit, retire, or delete durable context. The Reflection Compass aggregates only the caller's saved themes and approved memories.
